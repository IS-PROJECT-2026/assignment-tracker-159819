# Assignment Tracker 

A lightweight web-based system for managing and tracking academic assignments.

## Project Overview

The Assignment Tracker allows students to record, organize, and monitor their academic assignments, including deadlines, courses, priorities, and completion status.

## Planned Features

- Add assignments
- View assignments
- Edit assignments
- Delete assignments
- Mark assignments as completed
- Search and filter assignments
- Track deadlines and overdue assignments
- View assignment progress
- Persistent browser storage
- Responsive user interface
